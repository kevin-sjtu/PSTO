# Local performance measurements

No measured timing records, saved prediction arrays, numerical results or logs are shipped. Run these commands only after preparing local datasets and training the models. Their output describes the actual machine and run; it must not be substituted for an unmeasured paper result.

From the case root:

```bash
# Fine-step GPU runtime and endpoint error reference.
bash analysis/performance/benchmark_gpu_100.sh

# First complete the coarse evaluator, then compare both step sizes.
bash analysis/performance/benchmark_gpu_timestep_comparison.sh \
  --coarse-results analysis/results_1e-5/lie_10
```

The GPU protocol uses two warmup rollouts, five synchronized timed rollouts and two CPU threads, over reference frames 2000--2100. It requires CUDA. The comparison consumes the fine-step timing/accuracy files generated by the first command and the coarse evaluation records generated locally. `--require-device` can enforce a particular GPU name; otherwise the actual name is recorded. No paper source files or paper figures are required or modified.

The OpenFOAM benchmark requires the compatible Cantera-enabled `reactingFoam`, MPI, `foamDictionary`, `blockMesh`, GNU `/usr/bin/time`, a locally generated snapshot at `t=0.0001 s`, and compatible Cantera XML mechanism files. None of the snapshot or log data is bundled.

```bash
START_SNAPSHOT=/path/to/local/0.0001 \
CANTERA_XML=/path/to/local/h2o2.xml \
ELEMENTS_XML=/path/to/local/elements.xml \
NPROCS=128 bash analysis/performance/benchmark_openfoam_mpi.sh
```

It prepares an isolated temporary case and measures decomposition, 1000 solver updates of `1e-7 s`, and final reconstruction at `0.0002 s`. Input copies, mesh preparation and Python parsing are outside that timing scope. `FOAM_TEMPLATE`, `MPIEXEC`, and `BENCHMARK_OUTPUT` configure paths. Temporary files are removed on exit; `KEEP_WORK=1` retains the local working directory for inspection. This benchmark has not been executed during repository preparation.

Once the required local measurements exist:

```bash
python -B analysis/performance/plot_computational_performance.py
python -B analysis/performance/plot_timestep_performance.py \
  --coarse-results analysis/results_1e-5/lie_10
```

Both produce PNG figures locally; the timestep plot also writes a numerical summary for that local run. There is no implicit copy into the manuscript tree. A system serif fallback is used without bundling proprietary font files. Source JSON/CSV and generated figures remain excluded from the repository.
